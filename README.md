# OpenRad — AI Model Registry

OpenRad is an expert-curated repository of open-access AI models for radiology. It serves as a central hub for researchers, clinicians, and developers to discover, evaluate, and share open-source artificial intelligence models designed for radiological applications.

## Live Website
Visit the platform online at: **[OpenRad](https://konstvr.github.io/OpenRad/)**

---

## Project Overview

OpenRad provides a streamlined interface to navigate and evaluate open-access AI models in medical imaging. Key features of the registry include:
- **Model Discovery**: Search and browse through verified open-access radiology models.
- **Detailed Metadata**: Deep dive into model architectures, datasets, indications for use, and known limitations.
- **Rich Filtering**: Find models quickly by Modality, Use Case, Radiology Subspecialty, and availability of Weights/Demos.
- **Interactive Demos**: Launch live model demonstrations where available.
- **Community Contributions**: Submit new models to the registry.
